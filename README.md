# SAR-defocused-ship-collection
The dataset consists of 4,600 defocused ship SLC chips, including 2,300 simulated samples generated under three motion scenarios: translational motion combined with rotation about the X-axis, rotation about the X- and Y-axes, and rotation about the X-, Y-, and Z-axes; 1,300 real defocused ship chips acquired by GF-3 in spotlight mode; 500 real defocused ship chips acquired by Capella in spotlight, sliding spotlight, and stripmap modes; and 500 real defocused ship chips acquired by ICEYE in Dwell, spotlight, and stripmap modes. The spatial resolutions range from 0.3 to 1 m. This dataset is intended to support research on data-driven SAR ship autofocus methods.
